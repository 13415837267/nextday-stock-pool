## 落地改动

- `src/daily_run.py` (原 line 1808): 删除 `track.reverse()`，让 track 保持「当日首选 + history(新到旧)」
  的自然顺序，即新到旧。

  同信号日幂等生成的，顺序变了必须升版本号触发重算，否则页面上仍是旧顺序。
- 分支整理: 本地 `trae/agent-iJ4U0a` 与 main 完全同点(7e4ba92)、无分叉差异，且远程无此分支；
  切换 main 后删除本地多余分支，只留 main 一个分支。
- `.github/workflows/daily.yml`: 在「上传 Pages 产物」与「部署 GitHub Pages」之间加一个 `sleep 30` 等待步骤。
  连续两次(第274/275轮)部署遇到 GitHub 制品元数据最终一致性问题 —— upload-pages-artifact 上传成功
  (Artifact ID 已 finalize)后, deploy-pages 立即查询却返回 "Found 0 artifact(s)", 间隔仅约 0.5 秒。
  加 30 秒等待让制品元数据同步, 降低偶发失败概率(社区标准 workaround)。

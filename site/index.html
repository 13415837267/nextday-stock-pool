六、策略规则与披露

执行时点
  • T日收盘后：系统运行选股，发布「次日计划候选池」（评分前10只）
  • T+1日开盘集合竞价：单吊——仅买评分第1名1只、全仓进出；且仅当其开盘缺口 ≤ -2.40% 才入场，高开/一字放弃并顺延下一只
  • T+2日开盘集合竞价：全部卖出，资金复利滚动
  • 风控触发时（市场宽度<25% 或市场等权指数低于MA30）：次日空仓；连续风控超5个交易日后恢复参与（系数95%起步、每多1日+5%至满仓），且仅买缺口≤-2.75%的深低开票
  • 月度盈利熔断：当月已实现收益超30%后，后续买入降为60%仓位（抑制利润集中滚雪球）
选股条件（T日收盘：趋势内缩量回调）
  • 范围：沪深主板+创业板，非ST、非停牌、上市满120个交易日
  • 价格 3~150 元；成交额 ≥ 0.8亿；换手率 2%~15%
  • 当日涨幅 -6.0%~-3%（明显阴线回调）；距20日最低价≥5%（排除已深跌票）；收盘未跌停、非一字板
  • 量比 ≤ 3.0（缩量回调）；20日累计涨幅 5%~25%；20日乖离率 ≤ 8%
  • 收盘位置 ≤ 0.32：阴线收盘须在当日振幅区间下沿32%以内
  • 评分 = 0.30·z(20日动量) + 0.60·z(-乖离) + 0.05·z(-成交额) + 0.03·z(下影线) + 0.02·z(-量比)
披露
  • 回测为样本内结果，存在优化选择偏差；Walk-Forward 检验显示样本外信号为正但应打折：理性前瞻锚为月均 4~6%、回撤 -15%~-20%
  • 滑点敏感性：双边千2滑点下总收益由 2891% 降至 2041%；实盘务必限价单集合竞价执行
  • 单吊口径隔夜方差极大，绝对波动远高于分散组合
  • Bootstrap 置信区间（块长10日×3000次）：总收益 P5~P95 = +678%~+13631%（实际+3052%处于中位附近）；最大回撤 P5~P95 = -25.5%~-11.4%；重采样无法覆盖市场结构变化风险
  • ⚠ 长周期压力检验（2500交易日/2016-07~2026-10）：无熔断口径总收益 +166%（基准+41%）、最大回撤 -93%——策略优势依赖市场环境。已新增恐慌型波动熔断（十年信号扫描+走前验证：恐慌期信号均值-1.72%/胜率41%，双段一致），对近500日窗口零影响

五、策略规则

执行时点
  • T日收盘后：系统运行选股，发布「次日计划候选池」（评分前20只）
  • T+1日开盘集合竞价：单吊——仅买评分第1名1只、全仓进出；且仅当其开盘缺口 ≤ -2.5% 才入场，高开/一字放弃并顺延下一只
  • T+2日开盘集合竞价：全部卖出，资金复利滚动
  • 风控触发时（市场宽度<25% 或市场等权指数低于MA30）：次日空仓
选股条件（T日收盘：趋势内缩量回调）
  • 范围：沪深主板+创业板，非ST、非停牌、上市满120个交易日
  • 价格 3~150 元（压尾部：避开低价股连续跌停风险）；成交额 ≥ 2亿；换手率 2%~20%
  • 当日涨幅 -5.7%~-3%（明显阴线回调，避开近跌停票）；收盘未跌停、非一字板
  • 量比 ≤ 3.0（缩量回调）；20日累计涨幅 5%~25%（有前期趋势、非高位加速）
  • 20日乖离率 ≤ 8%（离均线越近，下跌空间越小——单吊核心安全垫）
  • 收盘位置 ≤ 0.34：阴线收盘须在当日振幅区间下沿34%以内（尾盘仍在出货的票次日反抽弱）
  • 评分 = 0.30·z(20日动量) + 0.50·z(-乖离) + 0.20·z(-成交额)；排序即买入顺序
交易保护
  • T+1开盘一字涨停或高开≥9%：放弃买入
  • 遵守A股T+1制度：当日买入的股票当日不可卖出，无任何当日卖出规则
  • T+2开盘跌停：保守按当日收盘价成交估算
  • 成本：佣金万2.5（双边）+ 印花税万5（卖出）+ 滑点千1（双边）

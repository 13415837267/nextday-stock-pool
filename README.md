# A股次日候选池系统

> 量化短线系统 · 数据源 [zzshare](https://github.com/zzquant/zzshare)（免费公开）· 全流程运行于 GitHub Actions · 结果自动发布到 GitHub Pages

## 一、系统简介

本系统是一个全自动的 A 股短线候选池系统：

1. **每个交易日收盘后**，GitHub Actions 自动通过 zzshare 获取全市场最新行情；
2. 按「趋势内缩量回调 + 次日深低开承接」（dip）策略执行选股，生成**次日计划候选池**；
3. 结果自动提交到本仓库（中文提交信息留痕）并**部署到 GitHub Pages**；
4. 内置**实盘口径复利回测**模块（每月/手动运行），验证策略「复利高、回撤低」。

**交易模式**：

```
T 日收盘后     系统选股, 发布次日计划候选池
T+1 日开盘     开盘集合竞价(09:15-09:25)买入深低开达标的候选票
T+2 日开盘     开盘集合竞价全部卖出, 资金复利滚动
```

## 二、在线页面

启用 GitHub Pages 后访问：`https://<你的用户名>.github.io/nextday-stock-pool/`

页面包含：次日执行计划、计划候选池（含入选理由）、大盘风控状态、回测绩效
（净值曲线/年化/最大回撤/夏普/胜率）、历史战绩（发布池实盘口径结算）。

## 三、选股条件（全部参数见 [config.yaml](config.yaml)）

**范围过滤**：沪深主板 + 创业板；非 ST、非停牌；上市满 120 个交易日。

**硬性条件**（T 日收盘）：

| 维度 | 条件 |
| --- | --- |
| 价格 | 收盘价 3 ~ 150 元（压尾部：低价股易连续跌停，是单吊最大尾部来源） |
| 流动性 | 当日成交额 ≥ 2 亿；换手率 2% ~ 15% |
| 回调 | 当日涨幅 -5.7% ~ -3%（明显阴线回调，避开接近跌停的票） |
| 量能 | 量比 ≤ 3.0（缩量回调，排除放量出货）；换手率 ≤ 15%（剔除高换手分歧票） |
| 趋势 | 20日累计涨幅 5% ~ 25%（有前期趋势，非高位加速） |
| 乖离 | 20日乖离率 ≤ 8% |
| 收盘位置 | T日阴线收盘价位于当日振幅区间**下沿 32% 以内**（尾盘仍在高位出货的票次日反抽弱；2026-10-22 由 34% 收紧至 32%，胜率 57.5%→60.5%、盈亏比 4.16→4.71） |

**评分排序（单吊口径，排序即买入顺序）**：`0.30·z(20日动量) + 0.60·z(-乖离率) + 0.10·z(-成交额)`。乖离权重最高——单吊场景下"离均线越近下跌空间越小"是核心安全垫；动量权重过高会排序到"强者深低开接飞刀"的票（扫描证实 mom 权重 0.4~0.6 时单吊收益转负）。每日发布池取评分**前 10 只**（`display_top_n`，供人工次日竞价审核，实际仅按顺序执行第 1 名）；回测/资金部署口径的观察池上限为 500 只（`top_n`），两者解耦。

**次日执行（竞价缺口承接，核心）**：T+1 开盘仅买缺口 ≤ **-2.40%** 的深低开票
（情绪错杀承接；-2.35~-2.44 为宽平台）；开盘高开 ≥ 9% 或一字涨停则放弃、顺延下一只。

**仓位管理（单吊）**：每日仅买入评分第 1 名 1 只，**全仓（约 100% 总资产）**进出，
T+2 开盘卖出后资金当日即可再投入。单吊口径的期望完全依赖横截面排序质量与深低开承接线。

**大盘风控（压回撤核心）**：全市场站上 MA20 个股占比 < 25%，或全市场等权指数 < 其 MA30 时，次日空仓。

**交易保护**：T+1 开盘一字涨停或高开 ≥ 9% 放弃买入；T+2 开盘跌停按保守口径估算；卖出资金当日即可再投入。**严格遵守 A 股 T+1 制度：当日买入的股票当日不可卖出，系统无任何"当日买入当日卖出"规则**——所有持仓最早于次一交易日开盘卖出。

## 四、数据持久化（增量更新）

行情数据保存在仓库 `data/panel/` 目录，**每交易日一个 csv.gz 文件**（全市场快照，约 230KB）：

- **首次部署**：一次性抓取近 660 个交易日全量数据并提交入库；
- **日常运行**：仅增量抓取缺失交易日（通常每天 1 个文件），无重复下载；
- 数据随 git 版本化，回测/选股直接读仓库文件，速度快且可复现；
- 数值列统一精度（价格 4 位小数、复权因子 8 位有效），控制仓库体积。

## 五、回测口径（实盘化）

- 复利滚动：初始资金 100 万，**每日单吊——仅买评分第 1 名 1 只、全仓进出**，卖出资金当日开盘再投入；
- 成本：佣金万 2.5（双边）+ 印花税万 5（卖出）+ 滑点千 1（双边）；
- 无未来函数：所有指标仅使用截至 T 日数据；前复权价格按复权因子精确计算；
- 停牌/一字板/大幅高开/缺口未达承接线等不可成交情形按规则跳过（顺延下一只）；退市等极端情况按保守口径处理；
- **近 500 个交易日实盘口径回测**：总收益 1797.80%，年化 340.80%，最大回撤 **-15.13%**，
  卡玛 22.53，夏普 2.81，129 笔交易，胜率 **60.5%**，盈亏比 4.71（同期
  市场等权基准 +60.82%，详见 Pages 回测绩效区）。

> **盈利月度集中度控制（月度盈利熔断）**：危机承接型策略的利润天然集中于暴跌后的
> 反弹月（原口径近12个月 79% 的盈利集中在 2026-04/06 两个月）。2026-10-22 起新增
> **月度盈利熔断**：当月已实现收益超 30% 后，后续买入降为半仓——全窗口最大两月盈利
> 占比 49.1%→**39.7%**，近12月 79.1%→**71.9%**；代价是总收益 2518%→**1798%**、
> 卡玛 27.66→22.53，夏普 2.69→**2.81**（收益曲线更平滑）。

### 三档口径对照（2026-10-22 实证，一键切换）

| 口径 | 配置差异 | 总收益 | 年化 | 最大回撤 | 卡玛 | 月均(几何) | 全窗top2盈利占比 |
|---|---|---|---|---|---|---|---|
| 稳健(当前默认) | 月度熔断30%/半仓 | 1797.80% | 340.80% | -15.13% | 22.53 | ~5.3% | 39.7% |
| 平衡 | 删除 risk.month_profit_cap | 2518.09% | 418.40% | -15.13% | 27.66 | ~6.8% | 49.1% |
| 极限 | 删除熔断 + block_reenter_frac: 1.00 | 3466.84% | 505.83% | -18.69% | 27.06 | ~7.4% | 55.3% |

> **关于"每月盈利50%"目标的实证结论**：500 交易日全参数空间扫描（120+ 组）的极限月均
> 约 **7.4%**（几何），单月≥50% 的月份在最优配置下仅 2 个，最差月 -8%。若要"每月+50%"
> 需 26 个月复利 **+1,220,000%**，超出该策略类别（T+1 单票全仓）的物理可能。以上三档
> 即为本策略收益-风险的实际上边界。

> **胜率-收益双高实现路径**：① 收盘位置过滤（阴线收在当日区间下沿 34% 以内）剔除
> "尾盘仍在出货"的坏票，使承接线得以从 -3.0% 放宽至 -2.40%；② 评分权重重优化
> （乖离 0.5→0.6、体量 0.2→0.1，排序更偏向"跌得浅、贴均线"的安全票）；③ 换手率
> 上限 20%→15% 剔除高换手分歧票；④ 承接线与大盘风控联动优化（gap-2.40 下
> MA28~30 为平台，MA32 以上递减）；⑤ 成交额下限 2.0→0.8 亿（0.6~0.8 为宽平台，
> 流动性约束放开后小票承接反弹弹性释放，总收益 571→751%、夏普 2.08→2.26，
> 半窗口前半大幅占优 100→175%/卡玛 9.1→20.3、后半小幅让步 253→227%）。
> 单吊模式绝对波动仍远高于分散模式，请务必知晓后再实盘。

### 为什么有的月份收益为 0（空仓避损说明）

回测中有几个月收益为 0（2025-01、2025-04、2026-06、2026-07、2026-10 等），这些全部
是**大盘风控触发月**（市场等权指数低于其 MA30）。它们是主动避险而非策略失效：

| 空仓月 | 同期市场等权 | 空仓避损 |
|---|---|---|
| 2025-01 | +0.09% | 0（横盘） |
| 2025-04 | -3.24% | +3.2pp |
| 2026-06 | -7.86% | +7.9pp |
| 2026-07 | -8.18% | +8.2pp |
| 2026-10 | -3.84% | +3.8pp |

**当前定稿已加入"最大连续空仓上限"**：连续风控超过 **5 个交易日**后，按 **75% 仓位**
恢复参与候选池，且超限参与日使用**更严的专属承接线 -2.75%**（弱市参与只接恐慌深跌票）——
短期风控仍全额避险，超长空仓期不再闲置资金。全窗口总收益 1274→**2518%**、卡玛 19.42→**27.66**、
夏普 2.60→**2.76**、胜率 57.5→**60.5%**、回撤 -14.14→**-15.13%**（+1pp，来自收盘位置收紧）；半窗口**双段占优**
（cp0.32+rf0.75: 前半 192→227%/回撤-11.0→-7.1%/卡玛17.7→32.4，后半 712→744%/卡玛51.3→50.2 持平）。参与系数在 cp0.32 下 0.74~0.78 为
回撤不变平台（0.80 起微恶化 -15.16%、0.85 → -16.05%，故取 0.75）。与整月降仓
（blocked_frac）不同：后者前半劣化 11pp/后半占优，时期依赖不稳定已证伪；"超限参与+
深承接"只在真正的长空仓期（2026-06/07）以更高门槛介入，短期避损完全保留，因此
收益、胜率、风险三项同向改善。连亏熔断（streak 2/3）亦证伪：熔断打断复利引擎，
收益崩至 18~34%。

回测运行方式：

```bash
python -m src.backtest            # 默认近500个交易日
python -m src.backtest --days 250 # 自定义窗口
```

结果写入 `output/backtest.json` 并展示在 Pages「回测绩效」区。

## 六、每日运行（云端）

- 触发：GitHub Actions 定时任务，北京时间**每交易日 15:30**（可手动触发 `每日选股更新`）；
- 流程：增量更新行情数据 → 选股 → 结算 T-2 发布池实盘战绩 → 写入 `output/` → 数据与运行记录中文提交留痕 → 部署 Pages；
- 所有数据与运行记录均以中文提交信息保存在本仓库，修改全程可追溯（另见 [CHANGELOG.md](CHANGELOG.md)）。

## 七、本地运行

```bash
pip install -r requirements.txt
python -m src.daily_run   # 手动运行一次每日选股(自动增量补数据)
python -m src.backtest    # 运行回测
```

可选提速：在仓库 Secrets 配置 `ZZSHARE_TOKEN`（在 [zzshare 官网](https://quant.zizizaizai.com)免费获取），提升接口访问频率上限。

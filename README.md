# A股次日候选池系统

> 量化短线系统 · 数据源 [zzshare](https://github.com/zzquant/zzshare)（免费公开）· 全流程运行于 GitHub Actions · 结果自动发布到 GitHub Pages

## 一、系统简介

本系统是一个全自动的 A 股短线候选池系统：

1. **每个交易日收盘后**，GitHub Actions 自动通过 zzshare 获取全市场最新行情；
2. 按「趋势内缩量回调」（dip）策略执行选股，生成**次日计划候选池**；
3. 结果自动提交到本仓库（中文提交信息留痕）并**部署到 GitHub Pages**；
4. 内置**实盘口径复利回测**模块（随每日流水线自动运行），验证策略「复利高、回撤低」。

**交易模式**：

```
T 日收盘后     系统选股, 发布次日计划候选池
T+1 日开盘     开盘集合竞价(09:15-09:25)按开盘价直接买入计划票
T+2 日尾盘     14:55 一次性全额卖出（开盘跌停等不可成交情形按规则顺延）, 资金复利滚动
```

## 二、在线页面

启用 GitHub Pages 后访问：`https://<你的用户名>.github.io/nextday-stock-pool/`

页面包含：**开场白（数据时间 / 回测口径 / 怎么看 / 纪律）**、次日执行计划、计划候选池
（含入选理由，**表内行数＝明日实际买入只数**）、大盘风控状态、回测绩效
（净值曲线/年化/最大回撤/夏普/胜率）、历史战绩（发布池实盘口径结算）。

## 三、选股条件（全部参数见 [config.yaml](config.yaml)）

**范围过滤**：**仅沪深主板**（第八十九轮按用户约束移除创业板）；非 ST、非停牌；上市满 150 个交易日（第一百零七轮 120→150：排除"次新过渡期"票，1500 日 +3218→+3327%、全史 +22058→+24731%，回撤均不变）。

**硬性条件**（T 日收盘）：

| 维度 | 条件 |
| --- | --- |
| 价格 | 收盘价 3 ~ 150 元（压尾部：低价股易连续跌停，是单吊最大尾部来源；第九十轮 300→150，主板单只口径 500 日 192.02%→212.61%/67笔/胜率76.12%，130~170 为平台） |
| 流动性 | 当日成交额 ≥ 0.8 亿；换手率 2% ~ 12%（第八十九轮 15→12：500 日 140.09%→195.27%、胜率 72.0→75.76%） |
| 回调 | 当日涨幅 -6.0% ~ -3%（明显阴线回调，避开接近跌停的票）；距20日最低价 ≥ 6%（排除已深跌票，反抽须是趋势内承接而非死猫跳；第九十轮 5→6，5.5/6.0/6.5 = 212.6/239.9/219.7） |
| 量能 | 量比 ≤ 4.0（允许「温和放量回调」入池：排除极致放量出货，但保留获利盘有序退出+新资金承接的中段回调；第一百零六轮 3.0→3.5、**第一百一十八轮 3.5→4.0**，见下方「边界随口径漂移」）；换手率 ≤ 12%（剔除高换手分歧票） |
| 趋势 | 20日累计涨幅 5% ~ 25%（有前期趋势，非高位加速） |
| 乖离 | 20日乖离率 ≤ **11%**（**第一百一十八轮 8%→11%**：旧上限把 20 日涨 15~25% 的强势股整体挡在门外，而「强趋势中的一次洗盘」赔率高于弱势股；9~12 在新口径下是连续平台，见下方说明） |
| 收盘位置 | T日阴线收盘价位于当日振幅区间**下沿 32% 以内**（尾盘仍在高位出货的票次日反抽弱；2026-10-22 由 34% 收紧至 32%，胜率 57.5%→60.5%、盈亏比 4.16→4.71） |

**评分排序（单吊口径，排序即买入顺序）**：`0.20·z(20日动量) + 0.70·z(-乖离率) + 0.05·z(-成交额) + 0.03·z(下影线) + 0.02·z(-量比)`。乖离权重最高——单吊场景下"离均线越近下跌空间越小"是核心安全垫；动量权重过高会排序到"强者深低开接飞刀"的票（第八十九轮 0.30/0.60→0.20/0.70，单只口径胜率与复利双升）。每日发布池**只取评分第 1 名 1 只**（`display_top_n=1`），**无顺延**：第 1 名即当日唯一计划；回测资金部署口径同为 1 只（`exec_top_n=1`，三端一致：网页展示 = 回测可执行池 = 执行判定卡）。500 只（`top_n`）仅作观察池诊断上限。历史口径 top10→top30→top5 变迁见下方梯度表。

**次日执行（开盘价成交，核心）**：T+1 开盘集合竞价**按开盘价直接买入计划票**，不设缺口门槛
（`buy_gap_below=0`；第九十三轮按用户执行要求定档——收盘后收到计划、次日开盘即买，不按低开幅度挑单）。
仅停牌、开盘一字涨停（物理买不到）、开盘涨幅 ≥ 10% 时放弃，当日空仓。

**评分分档下注（第九十六轮，替代第九十五轮的"≥1.5 才买"）**：首选票的综合评分是**当日候选池内的
横截面 z 分**。低于 **1.0**（`execution.min_top1_score`）才完全不参与；1.0 以上按 `execution.score_tiers`
分档给仓位：

| 评分区间 | 仓位（占 `alloc_frac_pct`） |
|---|---|
| ≥ 1.2 | 100%（满仓） |
| 1.0 ~ 1.2 | 100%（满仓；第一百零九轮 80%→100%） |
| < 1.0 | 不参与（空仓） |

为什么改：第九十五轮的"1.5 一刀切"单笔质量最好（+0.49%/笔），但**约 6 个交易日才 1 笔**，多数日子
页面是"今日不参与"。评分既然有排序力（单笔期望随门槛单调上升：无门槛 +0.01% → 1.3 +0.41% →
1.5 +0.49% → 1.8 +0.80%），就该用它决定"下多重"而不是"下不下"。

| 14 年全史（3378 日） | 总收益 | 最大回撤 | 笔数 | 单笔均值 |
|---|---|---|---|---|
| 第九十五轮：1.5 一刀切 | +890.1% | -46.8% | 532 | +0.49% |
| 第九十六轮：1.0 + 分档 | +1085.8% | -43.8% | 1119 | +0.28% |
| 第九十七轮：+ 高开减仓 | +1155.5% | -41.8% | 1119 | +0.28% |
| **第九十八轮：+ 分批出场（采用）** | **+2566.6%** | **-26.0%** | **1122** | **+0.43%** |

平台验证：门槛 0.95 / 1.0 / 1.05 / 1.1 与三套档位乘数共 8 组，全史 843~1101%、笔数 1005~1182、
1500 日 465~621%，是平台不是单点（对比单点 1.3 的 +1269.7% 与其左右邻居 793.8% / 901.1%——那才是噪声）。

**仓位管理（单吊 + 评分分档 + 高开减仓 + 池深分档 + 刀口剔除）**：每日仅买入评分第 1 名 1 只，
仓位由**四道减仓乘数**与**两道加仓乘数**叠乘决定，减仓端：评分档（≥1.0 即满仓）、高开档（×30%）、
池深档（30%~100%）；加仓端：恐慌日（×1.5，第一百七十三轮）、**池深 ≥40 只（×1.5，第一百七十五轮）**。
低分/高开/池浅的日子账上留现金，恐慌日/深池的日子可以突破满仓（透支部分付融资利息）。
**另有一道剔除规则**：刀口组（大盘平稳/上涨而个股独自跌破 −4pp）当日**不参与**
（第一百一十四轮起，原为 ×30%），把单吊唯一的名额让给真正的强信号。
T+2 卖出后资金滚动再投入（开盘腿当日可再投、收盘腿次日可投）。

**融资杠杆（第一百七十轮 `execution.leverage`）**：总敞口 = 权益 × **1.25**，透支部分按
`margin_rate=5.5%/年` 对持仓日逐日计息。依据：353 笔 μ=+1.435%、σ=4.871%，凯利 f\*=**6.05 倍**，
半凯利 3.02 倍 —— 满仓 1.0x 只是 1/6 注。1500 日 **6,875.6% → 18,585.7%**（年化 104.04 → **140.78%**）、
回撤 -17.74% → -21.74%（+4.00pp）、卡玛 5.87 → **6.47**、笔数 353 → 354（**不变**）；
全史 3053 日 年化 84.02 → **109.88%**、回撤 -22.09 → -26.98%、卡玛 3.80 → 4.07。
**只放大仓位、不改变选股**：1.0/1.25/1.5/1.75/2.0 五档笔数 353/354/354/354/352。
条件杠杆（只在高分/深池笔上加）经实测低于无条件固定杠杆，未采用。设为 `1.0` 即逐位回到旧口径。

**恐慌日超配（第一百七十三轮 `execution.mkt_boost_tiers`）**：信号日全市场个股涨跌中位数
`mkt_pct ∈ [-2.5%, -1.0%]` 时，这一笔的仓位再乘 **1.5 倍**（可突破满仓，融资额度同步放大）。
**这是全库第一条"加仓"规则**（第一百七十五轮又加了第二条，见下）—— 其余仓位规则
（评分档、高开档、池深档、刀口剔除）都是减仓。
为什么必须带下限：`mkt_pct ≤ -2.5%` 的样本均值是 **-1.61%**（接飞刀，趋势崩塌而非错杀），
而 -0.5%~-1.5% 这一段是 **+1.9%**；只判上限、不带下限的版本全史回撤从 -26.98% 恶化到 -33.36%，
还不如直接把杠杆调到 1.5x。加上 `[-2.5, -1.0]` 下限后双窗口同向：
1500 日 **18,585.7% → 46,480.4%**（年化 140.78 → **180.71%**）、回撤 **-21.74% 逐位不变**、
卡玛 6.47 → **8.31**、夏普 2.47 → 2.50、笔数 354 → 352、平均敞口 0.999 → 1.121；
全史 3053 日 年化 109.88 → **134.08%**、回撤 **-26.98% 逐位不变**、卡玛 4.07 → **4.97**。
**敞口只 +12% / +10%，年化 +28% / +22%** —— 均匀放到 1.12x 只能到约 124%，多出来的 57pp
全部来自"挑对日子加"。平台：下限 -2.0 = 177.94 / -2.5 = 180.71；倍数 1.3 = 164.71 / 1.5 = 180.71。

**池深加仓（第一百七十五轮 `execution.pool_n_boost_tiers`）**：当日**达标票数 ≥ 40 只**时，
这一笔仓位再乘 **1.5 倍**。`pool_n` 是 T 日收盘后通过全部 dip 条件并完成评分的票数（盘后即知），
既是"今天有多少票同时被打成缩量阴线"，也是**策略自己看到的恐慌强度** —— 与恐慌日超配的
"全市场平均跌了多少"是两个维度。第 99 轮的 `pool_n_tiers` 只做了"池浅降仓"，反方向从没测过。

分层（352 笔）：池深 0~10 +0.36% / 10~20 +0.75% / 20~30 +1.76% / **30~40 +0.54%（坑）** /
40~60 +1.92% / 60~100 **+2.92%（胜率 70.5%）** / 100+ +1.71%。交叉表证明与恐慌日不重复：
池深≥40 且市场跌 1~2.5% → 55 笔 **+2.95%**；池深≥40 但市场不在该区间 → 56 笔 +1.55%；
池深<40 且市场跌 1~2.5% → 19 笔 +1.67%；都不满足 → 222 笔 +1.02%。

同敞口对照（均敞口都是 1.373，纯杠杆 1.53x vs 本档）：

| 窗口 | 组 | 年化% | 回撤% | 卡玛 | 夏普 |
|---|---|---:|---:|---:|---:|
| 1500 | 纯杠杆 1.53x | 243.36 | -26.04 | 9.35 | 2.510 |
| 1500 | **池深加仓** | **265.31** | **-25.85** | **10.26** | 2.48 |
| 全史 | 纯杠杆 1.53x | 175.31 | -32.17 | 5.45 | 2.170 |
| 全史 | **池深加仓** | **181.25** | **-31.19** | **5.81** | 2.120 |

**收益更高、回撤更低 ⇒ 不是杠杆的变形。** 代价是回撤绝对水平抬升
（1500 日 -21.74→-25.85、全史 -26.98→-31.19，各 +4.1pp），属风险偏好变更；
不愿承担可把 `mult` 降到 1.25（221.78% / -23.80% / 卡玛 9.32）。
**门槛不能降到 35**：1500 日看着更好（273.51%），全史回撤从 -31.19% 崩到 **-39.49%**，
因为 30~40 那一档在 2012~2019 装的是崩塌期。

**闲置现金收益（第一百七十三轮 `execution.cash_yield`，缺省 0.0 不启用）**：策略年均只有约
24% 的交易日有持仓，其余时间现金空转。实盘可买国债逆回购/货币 ETF（年化 1.5~2%），
设 `0.015` 约合年化 +1.1pp。**不默认开启**：它不改变任何买卖判定，只是给净值加一条无风险
斜率 —— 开启后所有历史数字都会变好看，但那是口径变化，不是策略改进。

**高开减仓（第九十七轮 `gap_above_tiers`）**：T+1 竞价缺口 ≥ 0.5% 且首选评分 < 1.6 时，仓位再乘 **30%**；
评分 ≥ 1.6 的高开票不减。**照常成交、不弃单**，所以交易次数不变（545→545），只是"高开不下重注"。
依据：缺口 ≥ 0 的成交占 48%，合计几何期望 ≈ 0（0~2% 档 243 笔均值 +0.03%/胜率 44%，复利 -2%），
而低开才是 edge 来源（-2~0% 档 262 笔 +0.65%/57%，≤-2% 档 19 笔 +2.67%/89%）；交叉表里
"缺口 0~2% × 评分 1.0~1.4" 是 **-0.18%/91 笔**、"× 1.4~1.8" 是 -0.40%/85 笔，只有 "× ≥1.8" 才转正
（+0.87%/67 笔）——高开只在"强势股抢筹"时是正期望。1500 日 **596.26% → 776.02%**、回撤 -26.23% → **-24.45%**、
卡玛 1.47 → **1.80**，前后半窗 142.4/187.3 → 171.5/222.7（双段同向）；全史 1085.8% → **1155.5%**、
回撤 -43.8% → **-41.8%**。参数平台：乘数 0.2/0.3/0.4/0.5 = 804.6/776.0/748.2/721.1%（单调平滑）。
不取阈值 1.8（单窗口更高但 2.0 立刻掉到 1051.7%，非单调＝尖峰），取 1.6 与满仓档同义。

**卖出规则（第一百一十五轮 `sell_open_frac=0.00` 全额尾盘 + 第一百一十九轮极端浮盈例外）**：T+2 当日
**14:55 一次性卖出全部**；**唯一例外**是 T+2 开盘相对买入价浮盈已 ≥**15%**（≈两个涨停）时，改为**开盘价
全额卖出**（`sell_full_if_open_gain=15`，全史仅 4 笔触发，见下文"右尾"一节）；
若开盘跌停（物理上卖不出好价）则按当日收盘价保守估算。仅用 T+2 当日已实现信息决策，无未来函数。

为什么把 100% 压到收盘腿：**买入侧的"9:25 按开盘价买满"已证是买在日内最低**（第一百零四轮
`buy_open_frac` 0.8/0.6/0.4 = 1308/600/253% vs 基线 2775%）——卖出侧对称地，深低开承接后的
T+2 日内整体仍向上（全样本 T+2 日内均值 **+0.269%**、阳线率 51%），越晚卖越接近当日高点。
`sell_open_frac` 的历史是一条单调迁移线，每一步都是"前一个最优值的口径已经变了"：

| 轮次 | 取值 | 当时的理由 | 之后发生了什么 |
|---|---|---|---|
| 第九十八轮 | 0.50 | minimax 两腿等权，不猜日内方向 | — |
| 第一百零四轮 | 0.40 | 49 笔右尾在开盘见顶，只为证据调配比 | `market_ma` 30→20、`score_tiers` 取消 |
| 第一百一十一轮 | 0.10 | 新口径下卡玛峰值整体左移到 0.10 | `knife` 0.30→0（笔数 -28%）、`min_pool` 11→5 |
| **第一百一十五轮** | **0.00** | 第三次复扫：收益与卡玛 **全程单调**、无拐点 | 第一百一十六轮修 equity 计价 bug，曲线重测 |

第一百一十一轮当时看到 0.0 收益更高（1500 日 7307%，卡玛 7.18）却不敢取，理由是"笔数从 633 掉到 573，
样本结构已变"。第一百一十五轮在**旧引擎**上把笔数代价量成 76 笔（1500 日）/169 笔（全史）——
**第一百一十六轮修复 `equity` 漏计 `pending_cash` 的 bug 后发现，这个代价被夸大了约 4 倍**：

| 口径 | 0.10（原） | 0.05 | 0.02 | **0.00（现行）** |
|---|---|---|---|---|
| 1500 日收益 | 8633 | — | 9690 | **9974** |
| 1500 日卡玛 | 7.93 | — | **7.99** | 7.97 |
| 1500 日笔数 | 398 | — | 379 | **379** |
| 全史收益 | 122193 | 145592 | 159401 | **175170** |
| 全史卡玛 | 2.74 | 2.80 | 2.84 | **2.87** |
| 全史笔数 | 944 | 914 | 903 | **899** |

**效应分解（第一百一十六轮重做）**：0.10→0.02 全史只多 41 笔（944→903）、1500 日一笔不多（398→379），
收益却从 122193 涨到 175170（+52977pp）——**这是纯价格效应**：T+2 开盘价系统性低于当日收盘价
（深低开承接后的 T+2 是"修复日"，开盘是修复起点、收盘是修复终点）。0.02→0.00 再 +15769pp、笔数只少 4 笔，
仍是价格效应（卖得更晚）。**第一百一十五轮曾把后者解释成"资金效应：10% 回笼现金让三成仓票通过 30% 成交门槛，
跳过的恰是最差一档"——那个解释不成立**：2% 的现金本来也过不了 30% 门槛（需 9% 权益），
旧引擎之所以让它成交，是因为 `equity` 漏计 `pending_cash`、被缩成"当天回笼的那点钱"，
于是 2% 对 2% 自然通过。修复后这批"名义满仓、实际 2% 仓位"的注水单全部消失。

代价如实说明：①全史最大回撤 −24.72% → **−25.94%**（+1.22pp），1500 日 −14.23% → −14.69%（+0.46pp）；

### PIT 自查（第一百一十七轮）：三处隐性前视，全部修掉

时序层面本来就合规，这一点十年没变：**T 日收盘后**用截至 T 日的截面选股 → **T+1 开盘**按开盘价买 →
**T+2 收盘**（14:55）卖；风控用 T 日收盘算出的宽度/指数，只限制"次一交易日不买入"；持仓不到期绝不卖。
但"时序对"不等于"信息集对"—— 本轮按"**这条数值在 T 日收盘那一刻算得出来吗**"逐字段复核，
查出三处只有当天不知道、事后才知道的输入：

| # | 位置 | 问题 | 性质 |
|---|---|---|---|
| ① | `selector.build_indicators` 的 `low_tail`/`amp_pct` | 分子是未复权的 `high/low/open/close`，分母却是 `prev_close_adj`（相对**面板末日** factor 的前复权价）。`prev_close_adj = pre_close × factor/flast`，等于把结果除以一个"未来除权系数" k —— **越早的日期 k 越小，下影线被放得越大** | 直接用到未来除权信息；回测（窗口末日基准）与实盘（当日基准）算出的值不同 |
| ② | 同函数的 `dist_low20` | 用未复权 `low` 的 20 日滚动最低。窗口内若除权，`min` 取到除权前的高价，除权后现价被算成"低于 20 日最低"（负值），被 `dip_dist_low20_min=6.0` 错误剔除 | 数据口径缺陷（非前视，但会误杀） |
| ③ | `backtest.run_backtest` 传给选股的 `names` | 传的是 `client.stock_names()` —— **今天**的股票名称，用它匹配 "ST"/"退" 过滤历史行，等于提前知道"这票后来会 ST"。实测：当前 198 只 ST 里，平均 **148 只**在 1500 日窗口的某个历史日是正常票，约占当时全市场 **3.3%** | 典型前视（幸存者偏差的变体） |

**怎么发现的**：不是靠读代码猜，是靠**前视探针**——取同一段面板，把某日 D 之后的行整段砍掉重新算指标，
再和"用全量面板（含 D 之后数据、前复权基准在窗口末日）"在 D 日的选股结果比对。信息集干净的实现，
两者必须**逐位相同**：

| 探针日 | 修复前 | 修复后 |
|---|---|---|
| 20260212 | 候选 24 只、集合相同，但**评分差 0.001~0.012**（`low_tail` 差最多 8.44pp） | **完全一致（True）** |
| 20260604 | 候选 20 只、评分有微小差异 | **完全一致（True）** |
| 20261030 | 一致（末日无后续数据，本来就等价） | **完全一致（True）** |

评分差 0.008 看似无关紧要，但 `_zs` 是**当日截面排序**，相邻名次只差 0.01~0.05 —— 足以换掉单吊的那一只。

## 六、每日运行（云端）

- 触发：GitHub Actions 定时任务，主槽北京时间**每天 16:00**（cron 08:00 UTC），
  另有 **17:00 / 18:00 / 20:00 / 次日 06:00 四个补数据槽**——幂等守卫（`output/latest.json`
  的 `signal_date` 已是该交易日即跳过）保证一天只产出一次数据更新（可手动触发 `每日选股更新`）；
- **16:00 主槽为何可能晚些才落数据**：数据源当日全市场行情未必在 16:00 已出全。此时
  `daily_run` 解析到的"最新完整交易日"仍是上一日，与 `latest.json` 一致即幂等跳过，不会
  产出错误数据；由后续槽位在数据出全后补上。实际落地时间取决于数据源发布时刻；
- **为何更新可能落在凌晨**：GitHub Actions 的 schedule 为"尽力而为"调度，共享 runner 高峰期
  排队延迟可达数小时（本仓库 2026-10-26 实测延迟 6.3h）。多槽覆盖同一时间窗 + 幂等收敛，
  任一槽跑成即生效；即使跨日，次日 06:00 补漏槽也会把前一交易日补回来；
- 竞价确认任务已于 2026-10-31 停用：独立 workflow 删除，买入判定统一由前一交易日收盘后的
  `T+1 执行判定卡`（`output/latest.json` 的 `t1_decision`）承担，`tools/auction_confirm.py`
  仅保留作手工排查用，不再定时运行；第一百二十五轮起，`daily_run` 侧的「竞价确认 vs panel
  结算」对账与 `auction.json` 收盘刷新也一并移除（停更后该对账永远返回"非今日数据"，
  属每日执行却永不生效的僵尸路径），`output/auction.json` 已从仓库删除；
- 流程：增量更新行情数据 → 选股 → 结算 T-2 发布池实盘战绩 → 写入 `output/` → 数据与运行记录中文提交留痕 → 部署 Pages；
- 所有数据与运行记录均以中文提交信息保存在本仓库，修改全程可追溯（另见 [CHANGELOG.md](CHANGELOG.md)）。

## 九、自进化（自第一百二十二轮）

系统每周六 10:00 自动跑一次 `策略自进化` 工作流，对**人工预注册**的结构性假设做证伪。
它不搜索参数 —— 第一百二十一轮已经证明那个空间里全是噪声，`policy.autonomy.parameter = never` 从治理层禁死了这条路。

**它做的是三件不同的事**：结构进化（某个机制该不该存在，本引擎负责）、风控进化（滚动失效探针只告警不改仓）、参数搜索（禁止）。

### 三段信息隔离

| 窗口 | 区间 | 日数 | 角色 |
|---|---|---|---|
| `fast` | 2019-04-23 ~ 2025-06-30 | 1500 | 快筛：把明显变坏的挡在昂贵回测之外 |
| `extended` | 2012-11-30 ~ 2025-06-30 | 3053 | 主口径：收益/卡玛/回撤/分年一致性 |
| `holdout` | 2025-07-01 ~ 2026-11-02 | 325 | 封存区：**每年最多解锁 4 次，用一次记一次** |

> 封存区不是干净的样本外（现行 baseline 当年也见过它），但污染方向**不利于候选**：
> incumbent 在封存区上有选择优势，候选要赢只能靠增量。所以它是一道保守的门。

### 五道闸门

| 闸门 | 判据 | 不通过的语义 |
|---|---|---|
| G1 fast | 相对收益 ≥ −3%、Δ卡玛 ≥ −0.15 | 明确变坏 |
| G2 extended | 相对收益 ≥ +3%、Δ卡玛 ≥ +0.05、回撤恶化 ≤ 1.0pp | 全史维度不成立 |
| G2′ 噪声带 | \|Δ收益\| < 3% 且 \|Δ卡玛\| < 0.15 → `REJECT_NOISE` | 这个开关**根本没起作用**（与"被证伪"分开记账） |
| G3 分年 | 改善年份 ≥ 50%、最差单年 ≥ −5pp | 改善集中在少数年份 / 单年崩塌 |
| G4 邻域 | 相邻档位 Δ卡玛 ≥ −0.05 | 孤立尖峰，不是平台 |
| G5 holdout | 相对收益 ≥ +3%、Δ卡玛 ≥ 0 | 独立时段不确认（**预算已消耗**） |

`kind` 决定通过后怎么落地：`structure` 只开 PR 等人工合并、`risk` 可直接提交 main、`parameter` 连评估都不做。

### 首跑结果（2026-11-02，policy v1）

三个候选：一个被账本去重（`bias_115` 第一百二十一轮已判噪声），两个死在 G1 —— **没消耗一次封存区预算**：

| 候选 | 裁决 | 快筛 Δ收益 | 卡玛 | 笔数 | 结论 |
|---|---|---|---|---|---|
| `gapfloor_off` | `REJECT_FAST` | **−62.43%** | 5.60→3.52 | 387→366 | 撤销"深低开回满仓"，收益腰斩 —— 这条规则是收益来源，不是过度自信 |
| `knife_allow` | `REJECT_FAST` | **−33.46%** | 5.60→4.40 | 387→512 | 放开"大盘平稳而个股独跌"，多 125 笔、胜率 56.33→53.12%、单笔 1.369→0.915% —— 多出来的正是该砍的那批 |

两个方向都与"假设"相反，且幅度远超噪声带：现行规则在这两处是对的，而且是对的**很多**。

### 它的边界（写在最前面，防止被误读）

- **不会自己发明候选**。想让它评估新假设，必须在 `evolution/candidates.yaml` 登记 —— 没有登记就没有试验，这是对多重比较唯一的物理防线；
- **不会重复试错**：同一 patch 指纹 365 日内被拒过直接 `SKIP_KNOWN`；被否的候选不删，条目下补 `verdict` 写清数字；
- **不会给自己放权**：`policy.yaml` 引擎只读，改闸门必须人工 PR；封存区超过 500 日时由人工把 `holdout_start` 前推，引擎不能自己挪这条线；
- **不替代真样本外**。五道门只保证"在已实现的历史上，这个改动不是噪声、不是单年现象、不是对封存区的过拟合"。真正的 OOS 只有一个：从今天起冻结每日信号，用未来 6~12 个月检验。

|---:|---:|---:|---:|---:|

| 5000 万 | 4.54% | 63.3bp | 33.6% | 5.3% |
| 1 亿 | 4.85% | 65.8bp | 21.9% | 2.6% |

### 排序键与"隐形过滤器"（自第一百三十一轮）

T+1 9:25 竞价结束时，前 6 名的缺口全都可见，而策略只用第 1 名 —— 这个"用更新鲜的价格重排"
的想法看起来该有增量，实测是负的（1433 天 / 7621 条记录）：

| 规则 | 均值 | 换票率 | vs 现状 |
|---|---:|---:|---:|
| 现状：评分第 1 名 | +0.184% | — | 基准 |
| 前 2 名里缺口更深 | +0.011% | 25.5% | −0.174pp |
| 前 5 名里缺口更深 | −0.066% | 30.4% | −0.250pp（p=0.063） |
| 前 3 名里 score×\|缺口\| 最高 | +0.027% | 25.5% | −0.158pp |

- **决定性证据**：前两名都符合买入条件的 227 天里，第 1 名 +0.802% vs 第 2 名 +0.037%
  （差 +0.884pp, t=2.42）；**即使第 2 名的缺口比第 1 名深 1% 以上（29 天），第 1 名仍然不输**；
- 原因是信息层级：评分刻画"**为什么被错杀**"（乖离 / 缩量 / 低点距离 / 收盘位置），
  缺口只刻画"**今天怎么定价**"。前者是原因，后者是结果 —— 用结果覆盖原因必然丢信息。
  缺口该待的位置是**仓位**（`gap_floor_tiers` / `gap_above_tiers`），不是选票；
- **顺带发现**：满仓单吊 + T+2 收盘卖让资金天然"隔天才能再买"，而这个约束在过滤坏日子 ——
  "前一日也可买"的 213 天均值 **−0.388%**，"间隔日"356 天 **+0.527%**；按池深分层后
  满仓档是 **−0.155% vs +1.377%（差 1.53pp）**。也就是说：**资金约束本身是 alpha 的一部分**，
  降仓位 / 分仓 / 缩短持有期都会拆掉它（这正是 2×50% 分仓 1229% vs 单吊 6392% 的机制）。

### 资金配置：两条腿怎么分钱（自第一百八十五轮）

> **这是同一账户内的资金分配，不是两个独立策略各自达标。** 下表每一行都是"两腿按日收益加权合成的
> 一条净值"——它能回答"混起来曲线更平滑"，不能回答"第二个策略能不能单独赚钱"。

两条腿的日收益相关系数只有 **+0.085**（全史 +0.150）—— 不是参数不同，是物理互斥：
主策略买**缩量阴线**、持 1 日；副策略在低波池里追**风险调整动量**、持 10 日。

1500 日窗口（2020-08-28 ~ 2026-11-09），一个账户按权重分钱、按月再平衡、**不加融资**：

| 主策略权重 | 期末倍数 | 年化 | 最大回撤 | 卡玛 | 笔数 |
|---|---:|---:|---:|---:|---:|
| 100% | **498.29×** | 184.1% | -21.7% | 8.47 | 352 |
| 80% | 247.90× | 152.6% | -17.8% | 8.59 | 303 |
| **60%** | **116.14×** | 122.4% | **-14.2%** | **8.59** | 254 |
| 50% | 77.71× | 107.9% | -12.5% | 8.65 | 229 |
| 0% | 8.27× | 42.6% | -21.6% | 1.97 | 106 |

- **百倍不需要杠杆**：100% 主策略 498 倍，60/40 组合 116 倍，两档都过线。
  之前"百倍要 3.1 倍杠杆、代价 -55% 回撤"的说法错在只算了副策略 ——
  主策略是 H1 结构，一次满仓只占 2 天资金，复利靠周转次数而非杠杆。
- **全史 3053 日验证**：100% 主策略 **30,836 倍 / 年化 134.8% / -27.0% / 724 笔**；
  60/40 **2,316 倍 / 89.6% / -21.7%**。含 2015 熔断、2018 熊市、2024 微盘踩踏。
- **不是靠某一年**：2021 +359.8% / 2022 +389.0% / 2023 +47.1% / 2024 +186.4% /
  2025 +131.7% / 2026 +131.7%；滚动 252 日起点 **1249 个，最差 +27.4%，亏钱起点 0 个**。
- **60/40 的意义是"用 4.3 倍倍数换 7.5pp 回撤"**，不是"提高收益"。不在乎回撤就直接 100%。
- **硬约束**：满仓复利、无容量约束（池子门槛 1 亿成交额，500 万以上资金开始受压）；
  样本内（第 160 轮三重折扣后真实预期年化 **50~60%**，按 50% 算 6 年是 11.4 倍，不是 498 倍）；
  副策略全史只有 20.86 倍 / -48.9%，是"低相关第二腿"，不是第二台机器。

### 副策略的天花板：8.3×（第一百九十二轮定量）

副策略 1500 日 **726.7% / 106 笔 / 单笔 2.546% / 卡玛 1.95**。它到不了百倍，原因是结构而不是参数：

| 维度 | 最好的一格 | 说明 |
|---|---|---|
| 持有期（8 格：3/5/7/8/10/12/15/20） | **10 日（现行）** | 3 日 **−27.8%**、单笔只剩 +0.079%；笔数从 106 涨到 199，单笔从 2.55% 掉到 0.08% |
| 杠杆（6 格：1.0~2.5） | **1.75x = 24.9×** | 担保 151%；2.0x 担保 121%（历史最坏已破 130% 强平线），2.5x 只剩 88% |

结构恒等式：**106 笔 × 2.546% = 728%**。要 100 倍需单笔 **+4.4%**，而整条网格最高单笔 +2.64%。
主策略能到 **495×** 是因为 **352 笔 × 1.44%** —— 单笔低 44%，笔数多 3.3 倍，复利差 60 倍。
这就是 `(1+r)^n` 的形状。

结论：**主策略单独即达标，副策略的定位是低相关第二腿（压回撤），不是第二台机器。**
"一左一右、两个都百倍"在日线价量上不成立（第 186~192 轮共 4 次独立确认）。

### 为什么不挂限价等回踩（第一百九十四轮）

主策略是"T+1 开盘价直接成交"。很多人第一反应是"挂个 −1% 的限价，买便宜点"——**这在本策略上是负期望**，
而且是双窗口、三种挂法、全部更差。

| 方案（1500 日，基线 352 笔 / 单笔 +1.439% / 572.7×） | 笔数 | 成交率 | 单笔 | 终值 |
|---|---|---|---|---|
| 无条件开盘买（现行） | 352 | 100% | +1.439% | **572.7×** |
| 只挂 T+1，未触及空仓 | 243 | 69.0% | +1.449% | 109.6× |
| 挂 3 个交易日，未触及空仓 | 292 | 83.0% | +1.261% | 137.4× |
| 限价优先 + 未成交按收盘买（笔数不减） | 352 | 100% | +1.128% | 152.4× |

单笔几乎不动、笔数却掉三成 —— 复利缺口把终值砍到 1/5~1/8。3000 日（714 笔 / 39,383×）同向。

**为什么**：把 352 笔按"T+1 有没有跌破 −1%"分三档，是 U 型——

| 形态 | 单笔 | 说明 |
|---|---|---|
| 开盘即破 −1%（按开盘价成交） | **+2.08%** | 真正的超跌 |
| 盘中才破 −1%（按限价成交） | **+0.04%** | 日内阴跌 |
| 全天不破 −1%（限价不成交） | **+2.56%** | 强势票 |

限价单只在**最差那一档**成交：想买的强势票买不到，买到的都是继续走弱的票 —— **逆向选择**。
T+1 最低价平均比信号日收盘低 2.16%，但只有 11.4% 的日子"开盘即最低"，剩下的低点要靠日内阴跌才等得到。

**对照副策略（追强）**：同一条限价 −1% 规则是 **+0.40pp/笔**（+0.783% → +1.182%，成交率 73.4%）。
成交率几乎一样、符号却相反，因为"回踩"在上涨趋势里是洗盘、在下跌趋势里是趋势延续。
**执行规则不能脱离信号方向单独优化。**

### 候选池为什么只发布 1 只（第一百九十三轮）

页面上的候选池**表内行数 = 明日实际买入只数**。主策略一直是这个口径，副策略自第 193 轮统一
（旧版 `pool_show=4` 把第 1~4 名平铺，读者会以为可以改买第 2 名 —— 引擎里没有这个分支）。
依据是名次本身没有 alpha：

| 名次 | 1500 日（n=1399） | 全史（n=2899） |
|---|---|---|
| 第 1 名 | +0.600%（t=1.46） | +0.667%（t=1.79） |
| 第 2 名 | +0.733%（t=1.93） | +0.666%（t=1.92） |
| 第 3 名 | +0.828%（t=2.22） | +0.760%（t=2.28） |
| 第 4~6 名 | +0.55% / +0.66% / +0.60% | +0.44% / +0.50% / +0.48% |

同日配对差 **1−2 = −0.133%（t=−0.36）/ 全史 +0.001%（t=0.01）**，`1−3 = −0.228% / −0.093%`
—— **名次与收益无关**（第 3 名略高也落在噪声里，且属在 6 个名次里挑最大值）。
把候选池用起来的两种做法也都不划算：**2/2 并发卡玛 1.58、3/3 卡玛 1.93（vs 单吊 1.95），终值从 727% 掉到 327% / 405%**
—— 分散只是把同一笔钱摊薄。

那 2.546%/笔 从哪来：同一批票、同样持 10 日，只换进场规则 —— **开盘买 +0.78%（闸门开）→ 限价回踩 +1.18%**，
而提前离场（移动止损/闸门清仓）只贡献 **+0.094pp**。**钱在"低波池 + 回踩买入 + 大盘顺风"，不在"排第几名"。**

边界：106 笔的标准误 **0.891pp**（95% CI 0.80%~4.29%），同口径全样本 575 日只有 **+1.18%**，
完整落在区间内 —— 2.546% 不能当稳态期望。

网格由 `tools/make_combo.py` 每日从两腿净值重算（毫秒级，不重跑回测），页面在
「更多 → 资金配置」展示。
另有市场级**两融闸门**（融资余额 5/20 日变化、超额融资、融资买入比）：最好的一档把回撤从
-21.6% 压到 -17.4%、单笔从 +2.55% 提到 +3.27%，但放行率仅 18%、收益腰斩到 3.2 倍。

**为什么全否**（本轮唯一值得记的结论）：这些因子在**全市场**十分位单调（IC 显著），
但**低波池内全部拉平甚至反向** —— 池边界（IVOL 前 10%）与它们同源，二次筛选没有增量。
池内十分位极差只有 0.22pp，而单笔是 +2.55%，说明副策略的超额来自**入口条件与出口纪律**，
不在"挑哪一只"。故自本轮起，优化方向从"选股"转向"入口/成交"。

### 右侧交易的结论：111 个变体，天花板 22.5 倍（自第一百八十六轮，第一百八十七轮补全史）

用户问"能不能一个左侧抄底、一个右侧追高，两个都百倍"。把右侧做成**独立主力策略**
（不是补位、不是池内过滤），跑在与主策略完全同口径的引擎上（T+1 开盘买 / T+2 收盘卖 /
单吊满仓 / MA20+0.3 闸门 / 同成本）：

| 右侧形态 | 变体 | 最好结果 | 单笔 | 笔数 |
|---|---:|---|---:|---:|
| 追突破（含买入缺口上限 10%→-0.5% 扫描） | 10 | +15% | +0.14% | 146 |
| 趋势回踩（动量 12~45% + 缩量回踩 5 日线） | 15 | 880% | +0.65% | 447 |
| **趋势回踩 · 全史 3053 日** | 2 | **+92% / -92.9%** | **+0.27%** | 912 |
| 趋势回踩 · 全板块 / 只要 20cm | 8 | 7% / -61% | +0.11% / -0.38% | 508 / 374 |
| 趋势回踩 · 杠杆 1.0→2.5× | 9 | **22.5× / -62.6%**（2.0×） | +0.71% | 434 |
| **VCP 波动收缩贴新高**（O'Neil） | 8 | **-51% / 胜率 37.4%** | **-0.69%** | 139 |
| 涨停次日（T 日封板 + T+1 深低开承接） | 7 | +14% | +2.38% | 8 |
| 放量突破次日承接 | 4 | -28% | -5.87% | 5 |
| 卫星框架趋势回调 H3/H5/H10 | 9 | 1.65× | +0.64% | 149 |
| 扩槽位（2/3/4 只并发） | 4 | 183%（回撤降到 -36.7%） | +0.38% | 707 |

对照主策略 **498 倍 / +1.44% / 352 笔 / 卡玛 8.47**。右侧最好是 22.5 倍、卡玛 1.10、回撤 **-62.6%**。
加上第一百八十三轮的 26 个，**累计 111 个变体，0 存活**。

**两个关键补测（第一百八十七轮）**：

1. **右侧此前从未跑过全史**。1500 日 880% 而全史只有 **+92% / -92.9%**，单笔从 0.65% 塌到 0.27%。
   dip 对照：全史 724 笔 / 单笔 1.43%，与 1500 日的 1.44% 几乎一样——**dip 的 edge 12 年稳定，
   右侧的 edge 只在 2020 年后存在**（2015-2019 A 股动量是反转的）。
2. **右侧最优是不融资**。1.0× 给 912% / -36.6% / 卡玛 1.30；套主策略的 1.25× 反而退化到
   880% / -47.6%——5.5% 融资利息对单笔 0.65% 是重税。2.5× 也只能到 23.8 倍，回撤 -77%。

**为什么**：同模式内部把成交按 T+1 开盘缺口切 8 箱（排除选股差异）——

| 模式 | 低开成交 | 平/高开成交 | 最深低开箱 |
|---|---:|---:|---:|
| 主板 dip | +1.57% | +1.03% | **+4.03%**（17 笔，胜率 88.2%） |
| 追突破 | -0.09% | -0.16% | -1.19% |
| 趋势回踩 | +0.12% | +0.78% | -5.56%（6 笔） |
| 涨停次日 | -0.12% | **-1.51%** | +4.56%（4 笔） |

dip **每一格都是正的**；追突破**任何缺口箱都不赚**（包括低开箱）——不是"买贵了"，
是**信号本身没有期望**；涨停次日高开 >2% 的 73 笔单笔 -1.81%、累计 -130pp，是追高接盘的原样。

VCP 的结果把这条结论钉死了：它买在情绪最冷的一刻（贴高 3% 内、振幅 ≤4%、量比 ≤0.9），
依然单笔 **-0.69%**、胜率 37.4%——**问题在信号，不在成交价**。

**百倍线** `r(N) = 100^(1/N) − 1`：1500 日单吊 H1 每年约 76 笔、六年 458 笔，百倍需单笔 **1.01%**。
主策略 1.44%（超额 0.43pp）、右侧最优 0.74%（差 1.37 倍）、右侧全史 0.27%（差 3.7 倍）。
差这 0.27pp 靠杠杆补不上：2.0× 只把 10.1 推到 22.5（+123%），因为**杠杆放大波动、不放大期望**。
根子在卡玛：主策略 8.44 vs 右侧 1.30。

**我也测了"不属于右侧"的第二条腿候选，同样全否**：放量深跌反转 9 变体最好 209%/单笔 0.45%
（与 dip 物理互斥：缩量 vs 放量）；dip 互斥子集切分——深回调 98%/0.44%、更深 -12~-8% **-26%**/0.07%、
强趋势 140%/0.47%（**切出去就崩，且跌越狠越差**，反证现役 -6~-3% 是真峰）；
名次 1/2/3/5 = 1.44% / 0.67% / 0.82% / 0.88%（第 2 名腰斩，因为 dip 评分 `neg_bias20` 占 0.70——
第 1 名就是**乖离最低**那只，评分是按 alpha 强度排序，不是打分选股）。

结论：**"两个独立策略、一左一右、都百倍"在日线价量上不成立**，而且这套数据的十个方向已经挖尽
（见下节「数据资产还剩什么」）。可选 A 单策略 498 倍（建议）/ B 双池并行（创业板腿全史 -75%）/
C 主策略 + 低波防御（60/40 组合 116 倍 / -14.2%，定位是降波动不是第二台盈利机器）。

### 数据资产还剩什么（自第一百八十七轮）

| 数据 | 覆盖 | 状态 |
|---|---|---|
| 日线价量面板 | 2012-04 ~ 2026-11（3545 日） | **挖尽**（累计 132 个变体全否） |
| 两融余额 | 全史 3424 日 | 已用（第 184 轮 9 变体）：只能择时，放行率 18% 砍掉收益 |
| 财务（ROE / 增长 / 毛利） | 2016Q4 ~ 2026Q3（30 季） | 未用：季度低频，年化 20~25% → 10 年 9 倍 |
| 股指期货基差 | 2017-01 ~ 2026-11 | 未用：只能做择时增强，不产生独立策略 |
| **龙虎榜（净买 / 成交占比 / 换手 / 市值）** | **2016-01 ~ 2026-11（2564 日 / 15.5 万条）** | **已用（第 188 轮 62 变体）：全负** |

唯一有真实"右侧"信息含量的数据是**龙虎榜**——机构专用席位净买入、游资接力，是 A 股少数有
实证支撑的"跟随资金"信号，天然是右侧（上榜 = 异动已发生）。

**第一百八十八轮把历史补到 2016 年并验完了**：`data/lhb_hist/` 2,304 个交易日、12.85 万条，
合并后 15.5 万条。T+1 开 → T+2 开基准 **−0.735%/笔（t = −38.3，13 万笔）**，11 年每年为负；
38 个单维度格 + 60 个组合网格**全部为负**，最好 −0.122%。唯一为正的组合（+0.612%）靠收盘多扛
一天，但按年拆开**全部收益来自 2024 一年**，剔除后 10 年累计 0.0005x。

同轮用 1,350 万笔算了全市场结构曲线：按当日涨跌幅分 10 组，最好 D4 **−0.250%**、最差 D10
**−0.414%**，U 型且两端都亏——**"只看当日涨跌幅"本身不构成信号**。这也解释了主策略的 alpha
在哪：dip 买入的票落在 D1-D2（−0.374 / −0.275），却做到 +1.44%，那 1.8pp 只能来自"缩量"和
"MA20 上方"这两个形态条件，不是"买跌"。**左侧的 alpha 在形态，不在方向。**

**下一步不是补数据，是换频率**：日线价量（132 变体）与龙虎榜（62 变体）都已挖尽。要做出第二条
百倍腿只剩分钟级（T+0 打板，容量极小、需实时系统），或把现有主策略的执行做扎实。
继续在日线调参不会产生新结论。

### 向前台账（自第一百三十轮）

回测已经挖到噪声层，唯一还有新信息的只剩"向前看"。所以从 2026-11-02 起，每个信号日把
"当日选出的票 + 次日执行条件"原样冻结到 `output/paper.json`，之后只用真实行情回填：

- **只增不改**：记录一旦写入永不修改，只流转状态（待买 → 持仓 → 已结算 / 未成交）；
- **每日自动**：`daily.yml` 在回测之后跑 `python tools/paper_tape.py`，页面「五、向前台账」可看；
- **顺带校准容量**：每笔记 `open_rank`（开盘价在当日区间的位置）与 `vwap_prem_pct`
  （VWAP 相对开盘价），积累 30~60 笔即可替换容量表的 k=15/30 经验系数；
- **观察纪律**：单笔标准差约 6%，要 95% 置信区分"均值 > 0"需约 **61 笔 ≈ 一年**。
  前 20 笔的输赢不构成证据，只看偏离：均笔 vs 回测 +1.507%、胜率 vs 56.5%。

### 自检

```bash
python tools/test_patch_config.py     # 14 项: config 定点改写(标量/布尔/列表/嵌套/幂等/缺失键)
```

后者针对一个真实风险：首跑两个候选都死在 G1，**G3/G4/G5 从未被执行过**，而它们恰恰是唯一

三种边界反复重现，比用真回测赌一次便宜得多。
